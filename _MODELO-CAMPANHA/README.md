# _MODELO-CAMPANHA — não mexa aqui

Esta é a pasta-molde. Ela guarda a estrutura vazia + os templates que toda campanha nova recebe.

**Não trabalhe dentro dela.** Para começar uma campanha, na raiz do projeto rode:

```bash
./nova-campanha.sh nome-da-campanha
```

Isso copia esta pasta para `campanhas/nome-da-campanha/`. Trabalhe lá.

Se quiser melhorar o molde (ex.: ajustar os templates `publico.md`/`performance.md`), edite aqui — as próximas campanhas herdam a mudança.
