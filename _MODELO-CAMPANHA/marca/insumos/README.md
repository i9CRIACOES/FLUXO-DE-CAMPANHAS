# marca/insumos/ — material bruto do cliente

Jogue **aqui dentro** tudo que o cliente já tem, ANTES de rodar `/marca`.
Quanto mais material real, menos o Claude precisa inventar (e menos "PERGUNTAR AO CLIENTE" ele devolve).

## O que colocar (mínimo recomendado)

- [ ] **Site / landing page** — exporte em PDF ou salve o texto num `.md`, ou cole o link no comando
- [ ] **PDF comercial / apresentação de vendas** (proposta, tabela de preços, deck)
- [ ] **~10 posts que o cliente já publicou** (print, texto colado ou link) — é o que ensina o tom de voz
- [ ] **Depoimentos / cases / números reais** (faturamento, nº de clientes, resultados)
- [ ] **Materiais de marca existentes** (manual de marca, logo, paleta) se houver

## Formatos aceitos

`.md`, `.txt`, `.pdf`, imagens (`.png`/`.jpg`), ou links dentro de um `.md`.

> Dica: se o cliente só mandou link, crie um arquivo `links.md` aqui e cole as URLs.
> O `/marca` tem `WebFetch` liberado e vai ler cada uma.
